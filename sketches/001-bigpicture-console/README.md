## Variant: Big Picture (living-room console mode)

### Design stance
The TV/couch/controller mode: a PlayStation-like dashboard where the game pad is the first-class input and library == identity.

### Key choices
- Layout: pill-tab top nav switching full views (Home / Library / Consoles / Crew), gigantic scannable tiles, bottom sheet modals
- Typography: Archivo Black display caps — loud, console-OS energy
- Color: cosmic purple + cyan/pink glow on near-black
- Interaction: arrow-key tile focus movement, ESC/backdrop closes sheet, PLAY button animates a progress→"LAUNCHING" arc, live clock

### Trade-offs
- Strong at: emulator/consoles story, couch LAN nights with the crew, accessibility from across the room
- Weak at: unusable for managing queues/downloads on desktop; needs its UI siblings to carry that

### Best for
Mode you bolt on later — literally the "Steam Big Picture" persona of the same app.
