## Variant: Immersive Storefront ("Dockside")

### Design stance
Steam, but warmer — a cinematic dark store where "everything is free" is celebrated, not hidden. Feels like an app you relax in.

### Key choices
- Layout: slim icon rail + full-bleed hero carousel + horizontal art rows (Netflix/Steam hybrid)
- Typography: Sora, oversized 56px hero title
- Color: deep navy-black + lantern gold accent (pirate warmth without being kitschy)
- Interaction: rotating hero (arrows/dots), hover-reveal GET buttons, toasts showing magnet/Prowlarr-speak, live shrinking "queued GB" counter

### Trade-offs
- Strong at: emotional hook, selling the illusion of a real free-Steam, discovery browsing
- Weak at: dense power actions (downloads hidden behind one pill), throughput feels slow

### Best for
The main browsing moment — finding a game Friday night and hitting GET.
